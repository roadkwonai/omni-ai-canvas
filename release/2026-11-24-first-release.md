# Omni AI Canvas v0.1.0 — 첫 릴리스

대본부터 완성 영상까지 여러 AI 모델을 한 보드에서 쓰는 제작실의 첫 버전입니다. 내 컴퓨터에서 실행하고, 컷마다 어느 대본과 인물 참조로 만들었는지 보드에 남습니다.

## 할 수 있는 일

- **기획과 대본** 제작 형식 10가지로 시작합니다. 감독 에이전트가 시나리오와 씬, 샷을 제안하고, 공모전 요강과 레퍼런스 영상을 정리합니다.
- **이미지와 연출** 감정, 조명, 다각도를 바꿔 원본과 비교합니다. 디렉터 스튜디오에서 촬영 지시 169가지를 고릅니다.
- **영상과 3D** Higgsfield, Kling, Topview의 모델별 참조 칸을 채워 영상을 만듭니다. Blender 장면과 Tripo 리깅, 모션그래픽을 함께 씁니다.
- **대사와 목소리** 화자마다 목소리를 정해 대본을 한 번에 음성으로 만들고, AI가 제안한 연기 지시를 줄마다 고칩니다. Apple Silicon Mac에서는 API 키 없이 만들 수 있습니다.
- **편집과 보관** 컷, 전환, 음향, 단어 자막을 다듬어 MP4와 SRT로 내보냅니다. 보드 구조와 자산은 다음 작품에 다시 씁니다.

## 시작하기

Node.js 22.13 이상, Neon 데이터베이스, 영상 작업에는 FFmpeg 5.1 이상이 필요합니다. 설치는 [README](https://github.com/roadkwonai/omni-ai-canvas/blob/v0.1.0/README.md#빠른-시작), 사용 방법은 [사용 가이드](https://github.com/roadkwonai/omni-ai-canvas/blob/v0.1.0/docs/user-guide.md)를 보세요.

## 확인한 내용

- 자동 테스트 414개, lint, 타입 검사, 프로덕션 빌드를 통과했습니다.
- 랜딩과 사용 가이드를 1440px에서 320px까지, 제작실은 주요 화면을 브라우저에서 확인했습니다.
- macOS(Apple Silicon)에서 확인했습니다. 로컬 음성 생성 시간은 M1 Ultra 64GB에서 쟀습니다.

## 알려진 제한

- 로컬 전용입니다. 여러 사람이 접속하는 서버로 배포하기 위한 로그인과 격리는 없습니다.
- 유료 서비스의 생성은 각 계정의 사용량을 씁니다. 모든 유료 모델의 실제 생성을 이번에 다시 시험하지는 않았습니다.
- Windows, Linux, 실제 스마트폰, 화면 낭독기에서는 확인하지 않았습니다.
- 음성의 청취 품질은 사람이 평가하지 않았습니다. S2 Pro 결과는 연구와 비상업 용도로만 쓸 수 있습니다.
- 디렉터 스튜디오의 카메라 이동과 시간 표현 예제는 Blender로 만든 영상입니다.
- 이 저장소의 라이선스는 아직 정하지 않았습니다. 동봉한 스킬에는 각자의 조건이 있습니다.
