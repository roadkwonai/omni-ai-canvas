처음 시작하기

예제 작품을 열어 노드가 어떻게 이어지는지 보고, 첫 프로젝트를 만듭니다. 10분이면 끝납니다.

예제로 둘러보기

  1. 상단 프로젝트 이름을 누르고 마지막 상영의 열기를 누릅니다. 목록에 예제가 없으면 자동으로 만들어집니다.
  2. 기획 문서에서 대본, 캐릭터 시트, 키프레임, AI 영상으로 이어지는 선을 따라갑니다. 대본 카드의 책 아이콘을 누르면 본문을 크게 읽습니다.
  3. 키프레임을 선택하면 위에 이미지 도구가 나타납니다. AI 영상 노드에서는 5초 샘플을 재생합니다.
  4. 작업실의 기록 탭을 열어 봅니다. 생성을 요청하면 진행 상태와 결과가 여기에 쌓입니다.

첫 프로젝트 만들기

  1. 상단 프로젝트 이름을 눌러 새 프로젝트를 고릅니다. 이름은 120자까지 씁니다.
  2. 빈 보드로 시작하려면 무형식으로 시작을 그대로 둡니다. 작품 종류가 정해졌으면 제작 형식 지정을 고릅니다.
  3. 왼쪽 막대에서 노드를 하나 추가해 제목과 내용을 적습니다. 저장은 자동입니다.
  4. 생성을 요청하려면 설정 → 계정 연결에서 쓸 계정을 먼저 확인합니다.

설치와 첫 실행

Omni AI Canvas는 내 컴퓨터에서 실행합니다. 꼭 필요한 것은 Node.js와 Neon 데이터베이스이고, 나머지는 쓸 기능에 맞춰 나중에 설치해도 됩니다.

순서

  1. Node.js 22.13 이상을 설치하고 Neon에서 데이터베이스를 하나 만듭니다.
  2. cp .env.example .env로 설정 파일을 만듭니다. DATABASE_URL에 풀링 주소, DATABASE_URL_UNPOOLED에 직접 주소를 넣습니다. 필수 값은 이 둘뿐입니다.
  3. npm ci로 필요한 패키지를 설치합니다.
  4. npm run setup:check로 준비 상태를 봅니다. 확인 또는 설정 필요만 표시하고 값은 보여 주지 않습니다. 선택 도구가 설정 필요여도 계속할 수 있습니다.
  5. npm run db:migrate로 표를 만들고 npm run dev로 실행합니다.
  6. 브라우저에서 http://127.0.0.1:5050/studio를 엽니다.

이 컴퓨터의 음성 모델

S2 Pro는 약 11GB, Drama 3는 약 24GB를 내려받습니다. 받아 둔 S2 Pro 폴더가 있으면 npm run setup:local-tts -- 폴더경로로 다시 받지 않고 씁니다.

알아두기 다른 포트를 쓰려면 PORT=5051 npm run dev로 실행합니다. 외부 에이전트를 연결한다면 그쪽에도 SCENE_ROOM_PORT=5051을 줍니다. 개발 모드 대신 npm run build 뒤 npm start로 실행할 수도 있습니다.

씬 하나에는 씬, 대본, 샷, 키프레임, AI 영상, 타임라인 노드가 생깁니다. 패션 광고는 씬마다 5개이고 타임라인 하나를 함께 써 기본 9씬이 55개입니다. 씬은 직접 1~12개를 고릅니다. 시나리오에 맞춰 자동 결정을 고르면 씬 없이 공통 노드 9개만 준비하고, 감독 기획을 요청할 때 씬 수가 정해집니다.

이미 만든 프로젝트의 형식 바꾸기

캔버스 제목 옆의 제작 형식 또는 프로젝트 설정의 제작 형식 변경을 누릅니다. 노드는 그대로 두고 추천 도구와 지침만 바뀝니다. 부족한 노드까지 넣으려면 빠진 기본 노드와 연결 추가를 켭니다. 형식을 바꾸면 감독 기획에 적용하던 스타일 프리셋은 풀립니다.

내 보드 프리셋 저장하기
