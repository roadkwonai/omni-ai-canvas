# 공개 쇼츠에서 개인 프리셋과 새 작품까지

## 검증 영상과 분석 범위

[Smithsonian 공식 채널의 공개 쇼츠 · Holy Smokes! How the Smithsonian saves objects from disaster](https://www.youtube.com/shorts/iJlsITbVjFE)를 Omni AI Canvas에서 열었다. 영상은 약 90.3초, 720×1280이며 박물관 소장품 재난 대응 훈련을 소개한다. 화면 아래에 영문 글자가 보이는 장면이 있다. 이 원본은 참고 영상 노드에 연결했고 생성 입력에서 제외하는 연출 확인용 연결을 사용했다.

10fps 화면 변화 탐지에서 32개 컷 후보를 얻었다. 각 후보에 최소 하나의 표본을 배정해 96개 화면을 8장 시트로 전달했다. 전체 시간별 후보 272장 중 96장만 모델에 전달했으며, 컷 후보는 실제 편집점의 확정 목록이 아니다. 예를 들어 9.17초와 9.35초에 다른 화면이 보였지만 같은 컷 후보에 묶였다. 실제 실행 당시 화면 문자 OCR은 기존 8장 대표 프레임 기준이었다. 최종 코드의 컷 범위 재분석은 별도 검증 결과를 아래에 추가한다.

Codex가 반환한 32개 컷별 해석을 실제 시트와 함께 검토할 수 있도록 실행 기록에 보관했다. 예를 들어 컷 5는 4.65초 인물 정면과 6.15초 이후 화면 하단 중앙의 작은 흰 글자로 기록됐다. 프리셋 근거에는 원본의 관찰과 새로운 콘텐츠를 위한 해석을 구분하고, 음성·정확한 장비·프레임 사이의 움직임은 미확인으로 남겼다.

## 개인 프리셋과 새 작품

개인 프리셋 **동네 책방 복원 · 손상에서 다시 펼치는 순간까지**를 저장했다. 프리셋에는 훅, 손상 확인, 판단, 시연, 마무리의 다섯 구간과 각 구간의 구도·자막 지시가 있다. 기존 영상의 대사나 인물 대신 작은 책방에서 손상된 책을 살피는 새로운 소재를 사용한다.

저장된 프리셋을 Codex 감독 기획의 입력으로 전달해 **책이 마르는 동안**을 만들었다. 프로젝트에 40개 노드와 연결을 저장했으며 씬 3개, 대본 4개, 샷 8개가 포함된다. 책방지기 윤서가 빗물에 젖은 책을 확인하다 손을 멈추고 손상을 기록한 뒤 전문가의 점검을 거쳐 책을 선반에 돌려놓는 작품이다. 샷별 카메라·행동·연기·음향 지시도 보존했다.

같은 프리셋을 Codex의 로컬 모션 기획 요청에 전달해 18초·6장면의 타이포그래피와 카드 명세를 만들었다. 감독 대본의 이름과 맞추기 위해 제안된 인물 이름을 은재에서 윤서로 수정한 후 Omni AI Canvas에서 로컬 렌더했다. 결과는 720×1280 H.264 MP4이며 총 18초다. 원래 40개 노드를 유지한 채 렌더 설정을 담은 영상 노드 한 개를 더해 프로젝트는 총 41개 노드다. 새 영상 노드는 첫 씬 대본과 스타일 프리셋을 연출 확인용으로 참조한다. 4초 프레임에서 한글 문구와 카드 그래픽을 직접 확인했다.

로컬 모션 결과 영상 (로컬 자료) · 실행 `d059d4cf-aa8d-4a94-a703-feb2defe2653` · 결과 노드 `motion-take-491f7003-5b46-4300-aeeb-b85318f4a8d0`

첫 씬 대본은 윤서가 창가의 책을 두 손으로 받쳐 작업대에 놓고 책등의 틈과 질문 자막을 보여 주도록 구성됐다. 첫 샷은 1.5초 동안 책등 틈을 정면에 가깝게 잡고 종이 소리와 낮은 빗소리를 배치한다. 실제 책의 손상 상태를 판별하거나 보존 처방의 정확성을 검증한 결과는 아니다.

## 최종 코드의 구간 재분석

기존 원본에서 검출된 컷 후보 4~6을 구간 API로 다시 선택했다. 원본 3.635~9.07초의 표본 19장을 2개 세로 시트에 담았고 각 셀에 컷 번호와 원본 시각이 유지됐다. 개선된 화면 문자 인식은 CUT 5의 6~8초 구간에서 화면 중하단 글자를 반복 검출해 자막의 변화를 표시했다. 인식된 글자는 오탈자가 있어 원본 화면과 대조해야 한다.

범위 재분석 첨부는 `e39d02c7-0185-45f5-9882-10f04f7ae2a0`이다. 전체 원본 영상과 기존 프리셋·보드는 보존했다.

실제 Codex 구독 계정에 이 두 시트와 OCR 근거를 전달해 세 컷을 다시 분석했다. 컷 5에 대해 Codex는 4.65초 자막 없음, 5.08~6.65초 질문, 7.15~8.22초 안내 문구, 8.65초 자막 없음으로 판독했다. 화면 높이 약 65%에 흰색 한 줄이 놓인다는 구도 설명도 반환했다. 단일 시점 사이의 변화는 표본 간 추정 구간으로 읽어야 한다. 상세 실행 기록은 `a1094377-f2e9-4c35-b278-dbcfe38a7a6b`이다.
