# 랜딩 기능 소개 보강 제안

2026-11-24. B(연출 구간)는 구현했고 나머지는 제안이다. 시안에는 남은 목소리 구간과 기능 목록만 있다. [시안](mockups/landing-features.html) · [1440px 캡처](mockups/landing-features-1440.png) · [390px 캡처](mockups/landing-features-390.png). 이 문서는 [개편 제안](landing-redesign-proposal.md)의 3단계를 넓힌 것이다.

## 결론

1. **연출 구간을 새로 만든다.** 디렉터 스튜디오의 실사 예제를 랜딩에서 바로 눌러 본다. (구현함)
2. **목소리 구간을 새로 만든다.** 목소리 찾기, TTS 등록 샘플, 여러 화자 대사, 내 컴퓨터 음성을 한 흐름으로 보여 준다.
3. **도구 다섯 개를 작업별 기능 목록으로 바꾼다.** 여섯 작업으로 나누고 한 번에 한 작업만 보여 준다.
4. **제작 과정에 탭 두 개를 더한다.** 연출 고르기, 대사와 목소리.

## 지금 소개하는 것과 빠진 것

[사용 가이드](user-guide.md)와 제작실 화면의 기능 32가지를 랜딩과 대조했다.

| 작업 | 자기 칸이 있음 | 한 문장에 이름만 | 없음 |
| --- | --- | --- | --- |
| 기획 | 공모전 기획, 레퍼런스 컷 분석 | 감독 에이전트와 대본 | 문서 노드(Markdown·PDF), 제작 지침과 스킬 |
| 이미지 | 이미지 연출(감정·조명·다각도) | | 캐릭터 설정도·시트, 시트 분할, 레이어 분리·업스케일, 캐릭터 연출 키트, Soul 캐릭터 |
| 영상 | | 참조를 넣어 만드는 AI 영상 | **디렉터 스튜디오**, 리메이크·이어쓰기, 렌즈 전환, 클립 편집, 패션 광고 흐름 |
| 소리 | | 여러 화자 대사 음성, 음악과 효과음 | **목소리 찾기와 추천**, **TTS 등록 샘플**, **AI 연기 지시**, **내 컴퓨터 음성**, 목소리 녹음 |
| 3D·모션 | Blender, Tripo | 모션그래픽 | |
| 편집·정리 | 타임라인과 자막 | 보드 프리셋, 자산 보관함, 외부 에이전트 연결 | 프로젝트 관리 |

자기 칸이 있는 것은 6가지, 이름만 나오는 것은 8가지, 없는 것은 18가지다. 특히 소리와 영상이 비어 있다. 하위 기능을 어떻게 묶느냐에 따라 수는 조금 달라진다.

## 연출 구간 구현 결과

| 묶음 | 예제 | 출처 |
| --- | --- | --- |
| 카메라 이동 | 돌리 인·아웃, 돌리 줌, 줌, 팬, 틸트, 휩 팬, 랙 포커스, 핸드헬드. 보관함이 있으면 아크, 크레인, 드론도 | 로컬 보관함의 CineGuide 영상을 먼저 쓰고, 없으면 사진으로 직접 만든 영상 9개를 쓴다 |
| 구도와 앵글, 화면 배치, 카메라와 렌즈, 창의 시점 | 각 8개 | `public/director/examples`의 실사 사진 (구독형 `image_gen`으로 제작) |

`lib/director-showcase.ts`가 목록과 랜딩용 설명을, `app/director-showcase.tsx`가 화면을, `app/loop-video.tsx`가 첫 화면과 함께 쓰는 영상 재생을 맡는다. 영상은 화면에 들어올 때만 재생하고 직접 멈추면 다시 틀지 않는다. 모션 줄이기에서는 정지 화면으로 둔다.

### 직접 만든 카메라 이동

구독형 `image_gen`으로 사진 6장을 만들고 `scripts/director-photo-moves.mjs`로 움직임을 넣었다. 별도 과금 API와 영상 생성 크레딧은 쓰지 않았다.

| 움직임 | 만든 방법 |
| --- | --- |
| 돌리 인·아웃, 돌리 줌, 핸드헬드 | 인물을 macOS Vision으로 떼고 인물을 지운 배경 사진을 따로 둔다. 승강장을 바닥·지붕·양옆 벽의 상자로 보고 깊이를 계산해 가까운 곳이 더 크게 움직인다 |
| 줌 | 같은 장면에서 깊이와 상관없이 전체를 키운다 |
| 팬, 휩 팬, 틸트 | 넓은 사진과 긴 사진 위에서 화면을 옮긴다. 휩 팬은 프레임마다 14번 나눠 흐림을 만든다 |
| 랙 포커스 | 앞에 초점이 맞은 사진과 뒤에 맞은 사진을 자리를 맞춰 바꾼다 |

파일은 `public/director/moves`에 있고 960×540, 24fps, 무음이다. 아크, 크레인, 드론은 사진으로 자연스럽게 만들기 어려워 넣지 않았다. 인물은 움직이지 않는다. 돌리 인의 화면 가장자리에서 기둥 밑동이 잠깐 휘어 보인다.

## 문구

| 자리 | 제안 |
| --- | --- |
| 연출 제목 | 어떻게 찍을지 예제를 보고 고르세요 |
| 연출 설명 | 디렉터 스튜디오에서 촬영 지시 169가지 중에 골라요. 고른 지시는 이미지와 영상을 요청할 때 함께 보내요. |
| 연출 안내 | 예제 사진은 AI로 만들었어요. 실제 결과는 고른 모델에 따라 달라요. |

| 기능 목록 제목 | 필요한 기능을 작업별로 찾으세요 |

## 동작과 접근성

- 연출 예제는 고른 한 개만 재생한다. 사진을 먼저 보여 주고 영상은 구간이 화면에 들어온 뒤 불러온다. 모션 줄이기에서는 정지 화면으로 두고 재생 단추를 준다.
- 예제 카드는 버튼으로 만들고 고른 상태를 `aria-pressed`로 알린다. 갈래와 작업 탭은 지금 쓰는 UI SDK 탭을 다시 쓴다.
- 대사 음성은 누를 때만 불러오고 한 번에 하나만 재생한다. 대사 글자가 그대로 자막이 된다.
- 기능 목록은 모든 글을 처음부터 HTML에 넣는다. 탭을 바꾸지 않아도 검색과 화면 읽기에서 찾을 수 있게 숨김 처리 방식을 정한다.
- 320px에서 탭은 줄을 바꾼다. 시안처럼 옆으로 밀면 마지막 탭이 보이지 않는다.

| 390px 길이 | 연출 구간을 넣은 지금 8,694px(보관함이 없으면 8,577px). 목소리 1,158을 더하고 도구 1,169를 기능 목록 896으로 바꾸면 885px 는다 |

## 준비물과 순서

| 단계 | 내용 | 필요한 것 |
| --- | --- | --- |
| A | 기능 목록과 핵심 문장 빼기 | 없음. 문구와 탭만 바꾼다 |
| B | 연출 구간 **(구현함)** 과 제작 과정의 연출 탭 (남음) | 디렉터 스튜디오 캡처 |
| C | 목소리 구간과 대사 탭 | 대사가 들어 있는 예제 노드, 짧은 음성 세 개, 화면 캡처 |
| D | 제작 형식 네 묶음과 바로 시작 | 주소로 형식 고르기 (`components/Studio.tsx`) |

**A와 B를 먼저 하는 것을 권한다.** 새 음성이 필요 없고 빠진 기능 18가지 가운데 대부분이 이때 들어간다. 지금 예제 〈마지막 상영〉의 대본에는 대사가 없어 C는 예제부터 준비해야 한다.

## 지킬 것

- 음성은 배포할 수 있는 것만 쓴다. S2 Pro 결과는 비상업 조건이라 쓰지 않는다. Drama 3는 연 매출 50만 달러 미만의 상업 이용과 다른 음성 모델 학습 금지 조건을 확인한다. 직접 녹음한 음성이 가장 안전하다.
- 실존 인물 목소리나 Fish Audio의 공개 샘플은 랜딩에 올리지 않는다.
- 랜딩에는 Blender나 Three.js로 만든 예제를 쓰지 않는다. `tests/director-showcase.test.ts`가 막는다.
- 직접 만든 영상은 공개할 수 있다. 다만 사진은 AI 생성물이므로 화면에 그 사실을 적는다.
- CineGuide 영상은 이 컴퓨터에만 두는 참고 자료다. 로컬 보관함에 있을 때만 출처와 함께 재생하고 `public/`, 문서 캡처, 공개 저장소, 영상 홍보물에는 넣지 않는다. 다른 컴퓨터에서는 직접 만든 영상이 나온다.
- 목소리 개수는 수시로 바뀌므로 숫자를 적지 않는다. 촬영 지시 169가지는 `lib/node-director-presets.ts`에서 세며, 코드에서 계산해 넣는다.
- 로컬 음성은 Apple Silicon Mac에서만 된다고 같은 자리에 적는다.

## 인수 기준

- 랜딩에서 디렉터 스튜디오, TTS 등록 샘플, 여러 화자 대사, AI 연기 지시, 내 컴퓨터 음성을 각각 이름과 쓰임으로 찾을 수 있다.
- 1440·768·390·320px에서 가로 넘침이 없고 탭과 카드를 키보드로 고를 수 있다.
- 첫 화면에서 불러오는 파일은 늘지 않는다.
- 모든 수치와 조건을 코드나 문서에서 확인할 수 있다.
