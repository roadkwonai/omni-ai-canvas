# Dreamina 캔버스 실측

2026년 11월 22일 지정된 브라우저 계정의 열린 빈 캔버스에서 메뉴를 열고 닫으며 확인했다. 생성 요청과 파일 업로드, 노드 생성은 실행하지 않았다.

## 직접 확인한 화면

- 상단에 프로젝트, 자산 관리, 검색, 기록과 구독 관련 진입점이 있다.
- 캔버스 왼쪽 도구막대에 텍스트, 이미지, 동영상, 오디오, 타임라인, 요소, Cinema Kit, 3D 디렉터 콘솔, 이미지 편집기, 스티키 노트, 애셋 선택, 장치 업로드가 있다. 각 버튼의 생성 결과는 확인하지 않았다.
- 하단에는 선택, 미니맵, 연결 표시, 배율 조절이 있다. 빈 캔버스에서 선택, 미니맵과 배율은 비활성으로 표시됐다. 연결 표시의 동작은 확인하지 않았다.
- 채팅을 열면 크기 조절 가능한 에이전트 패널이 나타난다. `/` 스킬과 `@` 요소 멘션을 안내하며 동영상 분석, 샷 디자인, TV 광고, 내러티브 단편 영화, 전자상거래 이미지 진입점이 보였다.
- 채팅 첨부 메뉴에서 장치 업로드, 애셋 선택, 캔버스에서 추가를 선택할 수 있다. 실제 파일 첨부는 확인하지 않았다.
- 채팅 모델 메뉴에는 Dola Seed 2.0 Lite, GPT 5.5, GPT 5.6 Luna가 보였다. 이미지·동영상 설정은 별도의 탭으로 모델, 화면비와 해상도 옵션을 제공했다. 이용 가능성과 과금 방식은 확인하지 않았다.

## 제품 설계에 반영할 점

캔버스에서 제작 자산을 직접 추가하고 에이전트에서 기존 자산을 참조하는 흐름을 함께 제공한다. 대화 모델과 이미지·영상 모델의 선택 맥락을 구분하고, 결과의 생성 출처를 표시한다. 빈 보드에서 사용할 수 없는 조작은 비활성 상태를 분명하게 표시한다.

## 공식 설명과 확인 범위

위 내용은 해당 시점의 실제 화면 관찰이다. 공식 서비스의 기능 설명은 [레퍼런스 조사](research.md)에 별도로 기록했다. 이 조사에서는 생성, 노드 연결, 저장이나 구독별 기능 차이를 실행으로 검증하지 않았다.

## 후속 메뉴 확인 · 2026-11-22

기존 빈 캔버스의 검색은 이미지·동영상·오디오·텍스트·요소·타임라인·Cinema Kit·3D 디렉터 콘솔·그룹 등으로 필터링할 수 있었다. 기록 창은 이미지·동영상·오디오·텍스트 유형 탭을 제공했다. 자산 관리 패널에는 캔버스에 표시된 항목과 전체 탭, 검색·필터·다중 선택이 보였다. 각 패널을 닫아 원래 화면으로 복원했다.
