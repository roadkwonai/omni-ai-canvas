## 스타일과 자산 레퍼런스

- [Keyframe Gallery](https://keyframe.gallery/)는 제품 모션 영감을 모아 보여준다. 목록의 영상을 보고 선택할 자료로 기록한다. 개별 작품의 이용 범위는 해당 원본을 확인한다.
- [awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)는 공개 예제와 제작 프롬프트를 모은 색인이다. 작품별 사용 조건과 코드 라이선스는 각각 다를 수 있다.
- [AI City Builders Remotion](https://www.aicitybuilders.com/remotion)은 일반 HTML은 JavaScript 로딩 화면이지만 브라우저에서 실습 갤러리 44개 예제와 분류 필터를 확인했다. 캐릭터 분류에는 PNG의 등장과 말풍선, 호흡·흔들림을 조합하는 대기 동작, 스티커 처리가 있다. Omni AI Canvas에는 사용자의 캐릭터와 배경을 별도 레이어로 움직이는 방식을 적용한다. 갤러리의 예시 영상·인물·브랜드 원본을 제품에 담지 않는다.
- [Oneshotted](https://oneshotted.io/)는 키네틱 타이포, UI 설명, 데이터 시각화, 3D 등 분류와 제작 프롬프트를 제공한다고 소개한다. 현재 페이지에서 보이는 기능을 확인했고, 유료·로그인 후 항목과 MCP 계약은 따로 확인해야 한다.
- [Kenney Nature Kit](https://kenney.nl/assets/nature-kit)과 [Fantasy Town Kit](https://kenney.nl/assets/fantasy-town-kit)은 각각 CC0 3D 에셋으로 표시된다. 사용자가 Claude 요금제 안내 옆에 적은 두 번째 주소는 Fantasy Town Kit 페이지다. 외부 3D 에셋을 포함해 배포할 때는 내려받은 자산의 개별 안내를 보존한다.

## 구현 경계와 우선순위

현재 Omni AI Canvas 모션 숏은 여섯 가지 로컬 MP4 레시피인 키네틱 타이포, 수치와 진행 차트, 단계 설명, 카드 스토리, 이미지 깊이 연출, 캐릭터 컷아웃을 지원한다. 장면별 문구·길이·이미지와 색, 정렬, 모션을 지정하며 최대 10분까지 장면을 순차 렌더한다. 음향은 타임라인에서 추가한다. 레이어를 시간축에서 개별 편집하는 기능과 단어별 자막 강조, 관절·표정 애니메이션 캐릭터와 3D 씬, 중단된 렌더의 이어하기는 후속 설계다. 실제 동작과 검증은 [로컬 모션 레시피](local-motion-recipes.md)에 기록한다.

효과 이름만 늘리기보다 장면별 목표, 텍스트·미디어·도형의 상대 위치와 초 단위 타이밍, 사용자의 파일 참조, 출력 비율, 원본·변경 기록을 먼저 저장한다. 그 다음 동일한 시간 좌표를 사용해 브라우저 미리보기와 프레임별 최종 렌더를 맞추고, 장편은 구간 렌더와 합치기·재시도로 확장한다. 개별 코드, 이미지, 음원의 라이선스는 혼합될 수 있다.
