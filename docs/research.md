# Omni AI Canvas 선행 조사

조사일 2026-11-22. 이 문서는 제품 요구사항의 근거와 조사 시점에 확인된 제공자 기능을 기록한다. 서비스 기능과 계정별 이용 자격은 변경될 수 있다.

## 참고 영상 관찰

대상은 `resources/귀찮은 일 끝내려고 코딩 없이 만든 AI 도구·사이트 9종 [1080p].mp4`의 01:42~02:19 구간이다. 6초 간격 프레임과 동봉 한국어 자막을 함께 확인했다. 영상 속 도구는 **AI 캔버스샷**으로 소개된다.

- 01:42경 기획부터 생성과 편집까지 다루는 도구를 소개한다.
- 01:48경 기획, 이미지, 영상, 편집을 오가는 부담과 연결된 작업 카드의 필요를 설명한다.
- 01:54~02:01경 오른쪽 에이전트 채팅에 영상 설명을 입력하고 단계별 카드가 이어진 노드를 만드는 화면이 나온다. 상단에는 기획, 이미지, 3D 장면, 영상 생성, 음악, 영상 편집, 모션그래픽, 노드 추가, 첨부 기능이 보인다. 에이전트 선택에는 Claude Code가 보인다.
- 02:02~02:07경 이미지 노드에 모델, 예상 크레딧, 비율, 해상도, 품질, 프롬프트와 참조자료를 표시한다. 자막은 생성 비용을 미리 확인할 수 있다고 설명한다.
- 02:08~02:19경 GPT와 AI 플랫폼을 연결하고 기획 → 이미지 → 영상 → 편집이라는 작업 흐름을 설명한 뒤 채팅 가능한 노드를 구성하는 과정을 설명한다.

첨부 이미지의 기획 → 이미지 → 영상 → 편집 → 모션 연결도와, 여러 노드에서 참조 이미지를 분기해 각 장면 영상을 생성하는 캔버스도 같은 흐름을 뒷받침한다. 영상의 설명은 제작자의 시연이며, 외부 제공자와의 실제 연결 방식이나 과금 계약을 검증하는 자료는 아니다.

## 연동과 과금 조사

- Higgsfield 공식 MCP 안내는 OAuth로 기존 계정을 연결하고 기존 플랜 크레딧을 사용한다고 설명한다. MCP 생성에는 표준 크레딧이 차감되며 웹의 무제한 및 무료 생성 조건은 자동으로 적용되지 않는다. 구독 계정 연결 상태와 실행 전 비용 확인이 중요하다. [Higgsfield MCP 안내](https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp)
- Dreamina는 에이전트용 CLI를 안내하며 조사 시점에 Advanced 구독자 대상 비공개 베타라고 표시한다. 모든 계정에서 사용 가능한 것으로 가정하지 않는다. [Dreamina CLI](https://dreamina.capcut.com/ai-tool/install)
- Kling은 공식 CLI와 MCP에서 OAuth로 개인 계정의 유료 크레딧을 사용한다. 보너스 크레딧과 팀 혜택은 제외된다. TopView는 공식 OAuth MCP를 제공하며 무료·무제한 생성은 자동화에서 제외된다. 플랜별 사용 가능 크레딧을 연결한 계정에서 확인한다. [Kling 가이드](https://kling.ai/app/mcp/guide), [TopView 스킬](https://github.com/topviewai/skill), [TopView 요금표](https://www.topview.ai/pricing)
- ChatGPT, Claude, Antigravity의 소비자 구독, 로컬 CLI 로그인, 개발자 API 과금은 제공자별 별도 계약과 실행 경로를 확인해야 한다. 하나의 구독이 임의의 서버 API 호출을 제공한다고 가정하지 않는다.

## 요구사항으로 도출한 사항

1. 캔버스에서 문서, 시나리오, 캐릭터 시트, 장면, 키프레임, 이미지, 영상 결과를 노드로 배치하고 연결한다.
2. 연결의 방향과 참조 관계를 보존해 하나의 캐릭터와 장면 정보를 여러 생성 작업에 재사용한다.
3. 채팅으로 제작 의도와 작업 순서를 설명하고 생성된 노드를 검토·편집할 수 있게 한다.
4. 각 생성 작업의 제공자, 모델, 입력, 결과, 상태와 확인 가능한 예상 비용을 구분해 표시한다. 비용을 확인할 수 없다면 미확인으로 표시한다.
5. 로컬 CLI와 MCP 연동은 각 제공자가 지원하는 인증·권한·과금 범위 안에서 실행한다. 지원하지 않거나 연결되지 않은 제공자는 해당 상태를 표시한다.
6. 결과물과 연결 상태를 보존해 다시 열고, 변경 시 후속 장면에 필요한 참조를 확인할 수 있게 한다.
7. 장면과 이미지 결과를 검토한 후 후속 영상 작업을 진행할 수 있도록 단계별 수동 제어를 제공한다.
