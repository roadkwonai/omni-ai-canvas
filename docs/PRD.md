# Omni AI Canvas · AI 드라마 제작 캔버스 PRD

결정일 2026-11-22 · 대상 버전 0.1 · 제품 책임 단위는 한 제작자의 한 프로젝트다.

## 현재 구현 상태

감독 에이전트는 작품 형식과 장면 수에 따른 구조화 제작안을 제안한다. 사용자는 미리보기와 대본·연출 검토 결과를 확인하고 개별 반영한다. 씬·샷·레퍼런스 노드와 연결 역할, 생성 입력과 연출 확인용 구분이 추가됐다. 세부 제공자 지원과 실제 검증 범위는 [제공자 안내](providers.md)와 [실행 검증](verification.md)을 따른다. 자산 보관함, 보드 편집, 프리비즈·오디오 시간축과 로컬 연출 도구가 연결돼 있다. 기능별 검증 상태는 대응표에 기록한다. Higgsfield Seedance의 원본 영상 리메이크·이어쓰기 요청이 추가됐으며 실 유료 생성은 검증하지 않았다. 제공자의 요소 교체와 고급 레이어 편집은 별도 범위다. [제작 에이전트 사용 가이드](production-agent-guide.md)

에이전트 요청에는 프로젝트별 문서·이미지·영상과 공개 HTTPS 링크를 첨부할 수 있다. 일반 첨부는 대표 프레임과 내장 자막을 사용한다. 제작 프리셋의 전용 영상 분석은 컷 후보, 화면 문자 위치, 공개 자막과 선택적 로컬 전사를 추가로 사용한다. 첨부 처리와 제공자별 전송 범위는 [사용 가이드](production-agent-guide.md#에이전트에-자료-첨부)를 따른다.

## 목표와 대상

단편 드라마를 만드는 작가 겸 연출자가 한 줄의 아이디어에서 촬영 가능한 장면을 설계하고, 캐릭터와 키프레임을 다음 생성 작업에 이어 쓴다. 기존 구독 계정의 인증은 제작자 컴퓨터에 둔다. 첫 버전은 로컬에서 여는 한국어 Next.js 웹 앱이며 프로젝트 원본과 실행 기록은 Neon에 저장한다.

## 제작 시나리오

제작자는 예제 단편 **마지막 상영**을 열어 시나리오, 캐릭터 시트, 키프레임과 영상의 연결을 살핀다. 새 프로젝트에서는 에이전트에게 원하는 이야기를 설명한다. 제안된 노드를 검토해 반영하고 장면 대본과 캐릭터 묘사를 수정한다. 인물 참조와 대본을 키프레임에 연결한다. 선택한 계정으로 이미지를 만든 뒤 확정한 스틸을 영상 입력으로 사용한다. 직접 만든 파일이나 외부 서비스에서 내려받은 결과도 같은 노드에 붙일 수 있다.

| C3 제작 자료 | 기획, 시나리오, 캐릭터 시트, 키프레임, 영상 편집 | 한국어 제목과 본문을 입력하고 해당 자료를 다시 열 수 있다. |

| C6 이미지 | 텍스트와 참조에서 이미지 생성 또는 가져오기 | 실제 결과 파일을 미리 보고 저장된 노드에서 다시 연다. |

| C8 실행 관리 | 제공자 상태와 과금 경로, 실행 이력 확인 | 진행·완료·실패를 구별하고 실패 사유를 확인한다. 명시적 요청 한 번에 작업 하나만 생성한다. |
| C9 보관과 인계 | 원본 그래프 저장, 프로젝트 JSON 내보내기, 장면 순서를 지정해 MP4 내보내기 | 연결·텍스트·자산 참조를 내보내고, 선택한 영상의 순서와 오디오를 보존한 MP4를 내려받을 수 있다. |

`설정`에서 기획·텍스트·이미지·영상·음향 작업별 기본 에이전트와 모델을 지정할 수 있다. 기본값은 이 브라우저에 저장되고, 노드별로 지정한 선택을 우선한다. 저장한 계정이나 모델을 사용할 수 없으면 사용자가 작업 설정을 확인한다.

### 작업 공간 확장

- C2·C5. 작업실 상단의 **넓게 보기**에서 현재 탭과 입력 초안을 유지한 채 모달을 연다. Esc나 **패널로 돌아가기**를 누르면 원래 작업실의 확대 버튼에 포커스가 돌아온다.
- C2·C5·C8. 작업실의 다섯 탭을 가까이 배치하고 선택한 탭의 용도를 바로 표시한다. 작업실 상단의 **가이드**에서 첫 제작 흐름과 탭별 지침을 읽을 수 있고, 탭 아래의 **탭 사용법**은 해당 설명으로 바로 이동한다. 가이드를 닫으면 열었던 버튼으로 포커스가 돌아온다. 마우스와 키보드 포커스, **화면에서 기능 설명 보기** 모드에서 작업실 기능의 툴팁을 읽을 수 있다.
- C4·C6·C7·C8. 이미지·영상 프롬프트 위에서 파일을 첨부하거나 캔버스 노드를 연결하고 썸네일을 확인한다. 모델을 고른 뒤 실제 지원하는 옵션과 참조 역할을 지정한다. 씬 전체와 연결된 샷별 생성을 각각 시작할 수 있다.
- C3·C6·C7. 스토리보드, 캐릭터 시트, 질감 편집을 포함하는 제작 노드에서 **디렉터 스튜디오**를 열고 장면 행동, 카메라, 색감, 조명과 미술 지시를 저장한다. 노드를 다시 열면 값이 복원되고 이미지·영상 요청에 연출 지시가 포함된다.
- C3·C6·C7. 디렉터 스튜디오에서 각 프리셋의 용도와 대표 장면을 확인한다. 18~135mm 초점 거리를 선택해 고정된 예제의 가로 화각을 비교한다. 장면 전개 12개, 장르 10개, 편집 리듬 5개를 각기 선택하고 적용 후 다시 열어 확인한다. 창은 데스크톱에서 화면 가장자리에 16px만 남기고 열리며, 모바일에서는 화면 전체를 쓴다.
- C3·C4·C6·C7. 디렉터 스튜디오에서 구도 10개, 카메라 앵글 10개, 화면 배치 17개, 시선 4개, 카메라 이동 24개, 시간 표현 4개, 창의 시점 8개를 예제로 보고 고른다. 움직임 예제는 마우스나 초점이 닿은 카드 하나만 재생하고 움직임 줄이기 설정에서는 정지 화면을 보여준다. 이름·용도로 검색하고 카메라 이동은 종류별로 거른다. 고른 값은 창 아래에 항상 보이며 하나씩 해제한다. 서로 맞지 않는 선택은 알리고, 저장하지 않고 닫을 때 확인한다. 생성 요청에는 이름이 아닌 구체적인 지시를 보내고 정지 이미지 요청에서 움직임 지시를 뺀다. 로컬 참고 예제가 없거나 기록한 해시와 다르면 기본 예제를 보여준다. [설계와 출처](director-studio-reference-plan.md)
- C3·C6·C7. 디렉터 스튜디오에서 카메라 8개, 렌즈 8개, 조리개 7개를 같은 장면의 결과 사진으로 고르고 기준 사진과 반씩 나눠 비교한다. 요청에는 화면에 나타날 효과를 함께 보낸다. 초점 거리 예제는 18~135mm에서 인물과 배경 위치를 유지하며 세부 이미지를 겹쳐 선명하게 보여준다.

- C1·C3·C4·C9. 타임라인 창에서 화면비, 전체 길이와 컷·음향·자막 수를 항상 확인한다. 컷·음향·자막이 같은 시간축에 놓이고 합성 전에도 편집 화면에서 순서대로 재생한다. 컷 순서와 길이, 음향 시작은 시간축에서 끌거나 설정에서 정한다. 문제가 있는 항목은 이름과 이유를 표시하고 누르면 해당 설정이 열린다. 저장하지 않은 변경은 닫기, Esc, 다른 타임라인 열기와 새로고침에서 확인을 받고 버리면 저장에 실패한 값도 되돌린다. 390px과 320px에서도 가로로 넘치지 않고 같은 기능을 쓴다. [타임라인 안내](timeline.md)

- 좌측 제작 도구함에서 제작 키트로 노드를 추가하고, 캔버스 목록의 노드를 검색해 화면을 이동하며, 프로젝트 자산과 생성 결과를 가져오거나 재사용한다. 설정에서 시작 탭과 패널 배치를 조정한다.
- 우측 프로젝트 에이전트에서 현재 프로젝트의 대화를 열거나 새로 시작한다. 선택한 노드·파일·워크플로우와 같은 대화의 최근 맥락을 전송한다. 감독 기획은 기존 제작안 검토 경로로 연결한다.
- 노드 지침은 기본 지침, 스킬 출처, 작업 순서를 보여 준다. 사용자 직접 편집과 AI 수정 제안을 지원한다. 적용한 지침은 노드와 함께 저장하고 이후 요청에 포함한다. AI 초안은 사용자가 적용하기 전까지 노드를 변경하지 않는다.
- 확인 시나리오는 사이드바에서 노드 선택 및 생성, 프로젝트 대화 분리, 수정 지침 저장·다시 열기 및 실행 입력 반영이다.
- C3·C5·C9. 드라마 감독안에서 필요에 따라 내레이션·속마음 `[VO]`와 현장 밖 대사 `[OS]`를 구분한다. `[VO]`는 지정한 샷과 시점에 녹음 대사가 적힌 음향 큐로 배치한다. 제작자는 음성을 녹음하거나 파일을 첨부해 재생한다. `[OS]`는 소리 출처와 함께 씬 대본에 표시한다.
- C3·C4·C6·C7·C8·C9. 캐릭터 시트에서 외형과 목소리를 각각 저장하고, 재접속 뒤 학습 상태를 조회한다. 채택한 Soul 기준 이미지는 영상 입력으로 보낸다. VO 화자를 지정하면 발화 대사와 등록 목소리로 음원을 생성해 기존 타임라인 큐에 적용한다. 등록과 생성은 해당 Higgsfield 계정의 권한 및 지원 입력에 따라 실행한다. [세부 인수 기준](character-identity-design.md)
- C3·C4·C8·C9. 설정에 등록한 TTS 공급사의 목소리를 한국어 이름과 설명으로 살피고, 원문과 미리듣기를 확인한다. Fish Audio 목록은 인기순·최신순, 성별, 공급사 태그로 검색하며 페이지가 바뀌어도 조건을 유지한다. 대사 합성 결과를 원본 대본에 연결된 음향 큐로 추가하거나, 기존 음향 큐의 파일로 적용한다. 캐릭터 시트에 보관한 샘플은 권한 확인을 거쳐 Higgsfield 개인 목소리로 등록한다. 이 컴퓨터에 설치한 Fish S2 Pro와 Drama 3를 골라 API 사용량 없이 합성할 수 있다. 참조 음성은 Fish Audio 공개 샘플이나 프로젝트의 음성에서 고르고, 사용 권한을 확인한 뒤 생성한다. Drama 3에서는 성별·나이대·음색·분위기·장면으로 새 목소리를 설계하고, 두 로컬 모델에서 연기 지시·속도·음정·시드를 조합한다. Drama 3에서는 목표 길이를 정하고, 만든 음성을 기준으로 다시 연기한다. AI가 대본에 맞는 연기 지시를 골라 넣고 줄마다 이유를 보고 되돌린다. 대본에서는 화자별 목소리를 정해 여러 화자 대화를 한 음성으로 만들고 줄마다 다시 만들 수 있다. 생성 중에는 단계, 진행률과 남은 시간을 보고 취소할 수 있다. 목록은 끝까지 스크롤하면 다음 페이지를 이어 읽는다. [TTS 인수 기준](tts-studio-design.md)

### C2·C3·C4·C5·C9 · 레퍼런스 기반 제작 프리셋

- 제작자는 인플루언서, 공모전, 숏폼, 숏드라마, 드라마, 영화, 광고, 뮤직비디오, 모션그래픽, 애니메이션 숏 중 하나로 시작한다. 각 타입은 기법 선택과 연출 초기값, 고유한 제작 노드와 연결을 갖는다.
- 영상당 60분·1 GiB 이내 MP4/WebM, 접근 가능한 공개 YouTube 또는 프로젝트 영상을 최대 8편 추가해 대표 화면, 컷 후보와 자막을 확인한다. 파일 여러 편을 한 번에 선택하고 원본별로 상세 보기·비교·제거를 지원한다. 타입·아이디어만으로 텍스트 추천을 받거나 대표 화면을 읽는 에이전트로 분석한다. 사용자가 제안을 확인해 반영한다.
- 영상 길이에 대한 백분율로 훅·전환·마무리의 구간을 구분하고, 구간별 구도와 자막을 편집한다. 프리셋은 개인 보관함에서 저장·복사해 재사용한다. 이미 생성된 보드와 작업의 지침은 해당 시점의 스냅샷을 유지한다.
- 기본 노드를 배치하거나 감독에게 시나리오·대사·씬·샷을 요청한다. 활성 스타일은 프로젝트 대화에서도 참고한다. 모션 숏 제작자는 장면 문구와 길이, 색, 배치와 움직임을 편집해 로컬 MP4를 보드에 추가한다.

- C1·C4·C6·C7·C8·C9. 기존 광고 형식에서 Higgsfield 패션 광고를 고른다. 제품 사진과 인물·공간 참조, 샷과 시작 프레임, 씬별 영상 및 타임라인이 연결되고 전환·제품 검수 지침이 해당 노드에 적용된다. 프로젝트를 다시 열면 선택값이 복원된다. [워크플로우와 출처](higgsfield-fashion-ad-workflow.md)

- C4·C7·C9. 타임라인에서 인접한 영상 두 개의 연결점과 전환 길이를 고른다. 앞 테이크에서 렌즈 안쪽을 한 번 선택하면 안경테 안쪽 윤곽을 제안한다. 프레임별 원본 위에서 추적 윤곽을 확인하고 필요한 프레임만 보정해 다시 추적한다. 보정 프레임의 윤곽이 렌더에 반영된 결과를 재생한다. 합성의 페더는 윤곽 안에 제한하고 전환 후반에는 영상과 윤곽을 함께 확대한다. 적용하면 새 전환 노드와 연결을 저장하고, 두 컷의 대체 프레임만큼 잘라 편집 전체 길이와 자막·음향 위치를 보존한다. 적용할 때 원본 범위·초기 윤곽·프레임별 보정값을 저장한다. 전환을 다시 열어 보정·렌더·갱신하면 기존 클립의 결과가 바뀌며 컷 배치와 길이는 유지된다. 편집값이 없는 전환은 현재 앞뒤 컷과 원본 가이드 연결·전환 기록이 맞을 때 원본 범위를 불러온다. 앞뒤 컷이 달라 범위를 알아낼 수 없을 때는 원본 테이크와 각각의 시작 프레임을 직접 지정하고 윤곽과 보정을 새로 잡아 같은 클립에 저장한다. 시작 프레임은 숫자로 입력하거나, 해당 테이크의 미리보기에서 한 프레임씩 이동해 보고 있는 프레임으로 지정한다. 전환에 쓸 길이가 남은 경우에 시작점으로 지정할 수 있다. 저장한 전환을 열면 앞뒤 원본의 시작점을 미리보기에서 다시 고를 수 있다. 앞 시작점이 달라지면 저장한 렌즈 윤곽을 앞뒤 방향으로 새 기준 프레임까지 자동 추적한다. 겹치는 구간의 보정은 같은 원본 프레임에 유지한다. 옮긴 윤곽과 프레임별 추적 결과에서 필요한 점만 보정한다. 추적이 끊기면 첫 실패 원본 프레임을 열고 윤곽점을 보정해 목표 시작점까지 이어서 추적한다. 완료한 전환을 다시 열면 저장한 중단 지점의 보정을 확인할 수 있다. 같은 클립을 갱신한 뒤 시작점과 윤곽·보정값을 다시 불러온다.

### C2·C3·C4·C5·C7·C9 · Blender 장면과 선택형 제작 지침

- 제작자는 샷에 캐릭터와 배경 GLB를 등록하고 모델에서 읽은 본과 애니메이션을 선택한다. 포즈, 카메라의 시작·끝 좌표, 렌즈, 광원·환경광, 화면비, 길이와 프레임률을 저장해 다시 편집한다.
- 같은 장면으로 프리비즈와 최종 MP4를 로컬 렌더하고, 각 테이크에는 당시의 설정을 보존한다. 최종 테이크를 기존 또는 새 타임라인에 실제 길이로 추가하고 편집 결과를 출력한다. 다른 창에서 설정이 변경된 경우 렌더 당시 설정을 확인하고 보관한다.
- 사용자가 찍은 탑뷰나 다른 시점의 테이크에서 프레임을 추출해 대안 앵글의 시작 배치 자료로 사용한다. 연출 확인용과 제공자 생성 입력은 연결별로 구분한다.
- 장르별 Higgsfield 워크플로우에서 사용자가 배역별 음성 녹음·상태 참조·룸투어·대안 앵글을 선택한다. 숏드라마는 보관한 저자 원문의 100개 아이디어 중 하나를 골라 새 소재 기획에 참고할 수 있다.
- 감독과 노드에서 원문 출처와 지침의 실제 적용 내용을 열어 본 후 장르·역할별 추천을 적용하거나 수정한다. 선택 ID와 요약을 실행 당시 입력에 보존한다.
- 맥의 세 손가락 드래그가 브라우저의 기본 포인터 드래그로 전달되면 빈 배경은 패닝되고 노드 위에서는 노드가 이동한다. 박스 선택은 선택 모드에서 수행한다.

이미지·영상 공급사 직접 연동의 C6~C8 인수 기준은 다음과 같다.

- 캔버스가 연결된 공급사의 공식 목록에서 모델을 불러온다. 선택한 모델의 작업 방식, 제공 옵션과 이미지·영상 입력 슬롯을 표시한다.
- 사용자가 파일 첨부나 생성 입력 연결로 참조를 선택하고, 필요하면 시작·끝 프레임과 원본 영상 등 구체적인 입력 슬롯을 지정한다. 같은 공급사·모델·모드·설정을 견적과 실행에 사용한다. 필수 참조 누락이나 미지원 옵션은 실행 대기열에 넣기 전에 안내한다.
- Higgsfield·Kling은 로컬 공식 CLI, Topview는 Omni AI Canvas에서 로그인한 공식 MCP를 사용한다. 계정 인증이 안 된 상태에서는 생성 버튼을 비활성화하고 연결 안내를 보여 준다.
- 작업 번호를 기록한 후 결과를 조회한다. 유료 실행 대신 공식 조회, 모의 제출·결과 저장, 로컬 UI로 인수 검증한다.

동일한 프로젝트를 두 창에서 편집하면 오래된 버전의 저장은 충돌로 응답한다. 생성 실패는 편집한 내용을 지우지 않는다. 샘플과 실제 생성물을 화면에서 식별할 수 있어야 한다. 생성 전 제공자와 사용량 기준을 표시하며 금액을 알 수 없는 경우 예상 가격을 만들어내지 않는다. 데이터베이스, CLI, 미디어 오류는 사용자가 다음 행동을 정할 수 있도록 한국어로 전달한다. 키보드로 편집·저장하고 작은 화면에서도 선택 항목을 열 수 있어야 한다.

## 출시 범위

**C1·C2·C3·C4·C6·C7·C9.** `/`의 첫 화면에서 부제와 예제 결과 영상, 그 컷을 만든 대본·인물·키프레임·채택 컷을 확인하고 각 자료를 눌러 해당 제작 과정 탭으로 이동한다. 예제 영상은 소리 없이 재생되고 멈출 수 있으며 모션 줄이기에서는 정지 화면으로 시작한다. 좁은 화면에서는 메뉴 단추로 같은 안내를 연다. 소개 영상 구간에서 5분 영상을 재생하거나 장면 10곳 중 하나부터 본다. 재생을 누르기 전에는 YouTube에 연결하지 않는다. 연출 구간에서 디렉터 스튜디오의 실사 예제를 묶음별로 비교한다. 카메라 이동은 로컬 보관함의 영상을 출처와 함께 먼저 보여 주고, 없으면 사진으로 만든 영상을 보여 준다. Blender 예제는 쓰지 않는다. 비용과 보관 구간에서 API 키 없이 쓰는 길과 보관 위치를 확인한다. 제작 과정에서 보드·감정 편집기·타임라인·예제 영상을 전환하고, 제작 형식과 공모전·모션그래픽 등 단계별 기능을 확인한다. 좁은 화면에서도 원본 크기를 열거나 기능별 가이드로 이동할 수 있다. **캔버스 열기**는 기존 프로젝트 선택과 제작 흐름을 `/studio`에서 연다. 기존 프로젝트 링크는 컷 분석 식별자를 포함한 쿼리를 전달한다. 랜딩의 조회와 예제 재생에는 공급사 실행이 필요하지 않다. [랜딩 페이지 설계](landing-page-design.md)

개인용 제작과 장면 단위 결과를 먼저 제공한다. 팀 권한·공개 공유, 여러 기기에서의 미디어 동기화, 전문 멀티트랙 편집·자막·고급 전환 효과, 자체 결제는 후속 범위다. Kling 공식 CLI는 개인 계정 유료 크레딧, Topview 공식 MCP는 연결한 계정의 자동화 이용 조건을 적용한다. Higgsfield에서 선택한 Kling 모델의 크레딧은 Higgsfield 계정 기준이다.

### C1·C6 · 프로젝트 관리와 작업실 연결

- 프로젝트 관리에서 최근에 열거나 수정한 순서로 작업 중, 보관함, 휴지통을 확인한다. 제목·카테고리·태그 통합 검색과 카테고리·태그 조합 필터를 지원한다.
- 프로젝트 목록의 설정과 우측 프로젝트 패널의 설정에서 같은 모달을 연다. 이름과 카테고리 한 개, 태그 최대 20개를 편집하고, 기존 분류 선택, 프로젝트 복제·보관·휴지통 이동을 지원한다.
- 카테고리·태그 선택 옆에서 해당 분류의 설정을 바로 연다. 전용 설정과 프로젝트 관리 상단의 카테고리·태그 전체 관리에서 공유 분류를 추가·변경·삭제한다. 전용 설정을 닫으면 기존 프로젝트 설정의 초안을 유지한다. 사용 중인 프로젝트 수를 표시하며 이름 변경과 삭제는 보관함과 휴지통을 포함한 모든 사용처에 반영한다. 프로젝트에 붙인 분류만 제거할 수도 있다. 목록과 검색 필터는 저장한 분류를 반영한다.
- 작업실에서 API 키를 등록·교체·삭제하고 저장한 키로 읽기 전용 인증을 확인한다. 서버는 키를 브라우저로 반환하지 않는다.
- 기본 에이전트와 작업 공간 배치는 다른 브라우저에서도 같은 값으로 열린다. 이미지 기본값은 Codex `image_gen`이다. 별도 과금 이미지 API는 해당 API의 허용 설정을 저장한 경우에만 견적·등록·실행을 진행한다.
- 공식 CLI/MCP가 제공하는 요금제, 잔여 크레딧, 계정에서 조회된 모델을 표시한다. 공급사에서 값을 제공하지 않는 경우 조회할 수 없다고 표시한다. 작업별 기본 모델은 새 노드에 적용되고 작업에서 지정한 선택은 우선한다.


- 작업실 계정 카드에서 Codex·Claude·Antigravity의 공식 인증을 열고, 연결 해제 전 공유 CLI 영향과 완료 방법을 안내한다.
- 최근 계정 상태를 즉시 표시한 뒤 백그라운드에서 갱신한다. 조회 시각을 안내하고 인증 변경 뒤 이전 상태를 무효화한다.
- 작업실 설정·프로젝트 관리·노드 편집은 키보드와 좁은 화면에서도 주요 동작을 찾고 완료할 수 있어야 한다.
- C2·C3·C9. 문서형 노드에서 보기와 편집을 전환하고 마크다운 제목·표·목록과 원문을 확인한다. 저장한 제목과 본문이 카드 및 새로고침 후 모달에 반영되고 편집 취소는 마지막 저장 내용을 복원한다. 원문을 개별 Markdown으로 내려받고 마크다운 서식을 적용한 PDF 파일을 직접 내려받을 수 있다.
- C2·C3·C6·C7. 키프레임과 영상 등 다른 노드의 전체 본문과 첨부를 미리보기에서 확인한다. 이미지를 확대하고 영상·음향을 재생할 수 있다. 미디어가 없는 노드도 본문을 표시하고 닫으면 노드로 포커스를 복원한다. 미디어를 원본 파일명으로 바로 내려받는다. 미디어 프롬프트를 생성할 때 영문·한국어 버전을 함께 저장하고 미리보기에서 영문 아래 한국어를 표시한다. 어느 언어를 수정해도 적용 시 두 버전을 함께 갱신한다. 미리보기는 콘텐츠에 맞춰 열리고 드래그·방향키로 크기를 바꾸거나 기본 크기로 복원한다.

## C1~C9 · 제작 형식, 보드 프리셋과 이미지 편집

- C1·C5. 새 프로젝트는 무형식, 제작 형식 10종 또는 저장한 보드 프리셋으로 시작한다. 상단과 프로젝트 설정에서 적용 중인 형식을 확인하고 변경한다. 직접 지정하는 씬 수는 1~12개다. 자동에서는 공통 기획 노드로 시작하고, 감독 기획을 요청하면 시나리오·대본·선택 자료를 바탕으로 씬 수를 제안한다. 제안의 씬 수를 확인하고 채택할 수 있다. 형식을 바꾸거나 해제해도 편집한 노드와 자산이 유지된다.
- C2·C3·C4·C9. 입력·출력 포트의 ＋에서 자료를 연결하거나 후속 노드를 만든다. 후속 노드는 종류별 선택 카드에서 고른 뒤 추가하고 연결한다. 이미지가 있는 노드에서는 이미지 연출 편집도 열 수 있다. 전체 또는 선택한 구조를 보드 프리셋으로 저장해 다시 시작할 수 있다. 작품 본문, 자막 원문, 미디어와 실행 정보는 새 작업에 복사하지 않는다.
- C2. 캔버스에서 트랙패드 두 손가락 스크롤은 가로·세로 이동에 사용한다. 두 손가락을 벌리거나 오므리면 조작 위치를 기준으로 확대·축소한다. 배치 최적화로 이미지·영상이 붙은 카드 사이의 간격을 확보한다. 새 노드는 겹칠 때 가까운 빈 자리로 이동한다. 미디어를 붙인 카드가 커져 겹칠 때는 겹친 이웃을 옮긴다. 자동 조정과 원래 작업은 한 번에 실행 취소한다. 노드와 연결은 보존되며 실행 취소나 다시 실행으로 배치를 전환한다. 저장한 위치는 새로고침 후에도 복원된다.
- C4·C6·C8. 이미지가 붙은 노드에서 질감, 감정, 시점, 조명, 시네마틱 룩과 시트를 위한 편집 노드를 만든다. 모델 실행에는 원본 이미지가 첫 참조로 들어가며, 채택 전 원본과 후보를 확인할 수 있다. 작업 중 실제 입력 연결만 움직이며 모션 줄이기 설정에서는 방향 표시를 유지한다.
- C2·C4·C6·C8. 이미지 선택 시 상단 도구에서 감정·조명·다각도 편집 노드를 한 번에 만들고 설정 편집기를 연다. 5×5 감정판의 각 칸을 선택하면 그 좌표에 해당하는 기준 표정 사진을 표시한다. 감정판을 드래그하면 가까운 좌표의 기준 사진과 이름을 표시한다. 감정 선택과 저장·생성을 화면 크기에 맞춘 대화상자에서 쓸 수 있다. 조명·다각도 등 이미지 연출 설정과 업스케일에도 같은 대화상자 크기 규칙을 적용한다. 조명 가이드에서는 원본을 기준으로 주광 기구와 광선을 확인하고, 드래그와 프리셋으로 방향을 바꾼다. 정면·투시 보기에서 같은 방향을 가리키며 림라이트를 켜면 보조 기구가 보인다. 저장과 새로고침으로 편집 설정을 다시 확인한다. 실행 전 계정과 사용량 조건을 표시한다.
- C2·C4·C6. 이미지 툴바와 좁은 화면의 더보기에서 레이어 편집, 캐릭터 설정도, 업스케일, 주석, 회전, 다운로드, 미리보기를 연다. 레이어와 픽셀 편집 결과는 원본과 연결돼 저장된다. 업스케일과 회전 값을 다시 열어 확인한다.
- C6·C7·C9. 2×2, 가로 3칸, 3×3, 5×5 시트의 분할 경계와 선택한 칸을 미리 본다. 채택한 칸만 파일과 키프레임으로 저장하고 ＋에서 영상 노드의 시작 프레임으로 이어갈 수 있다.
- C2·C4·C6·C8. 조명·감정·다각도·질감·영화급 보정과 시트 도구를 선택하면 각각의 편집 노드가 원본에 연결된다. 화면에서 조절한 설정은 저장하고 새로고침 뒤 복원한다. 조명 등 이미지 편집에서 원본, 채택본과 후보는 편집기 안의 대화상자에서 확대하고 후보별로 채택한다. 모델 실행은 제작자가 확인한 설정을 고정한다.
- C4·C6·C7·C9. 25컷 시트의 내용과 개별 경계를 확인한다. 현재 원본과 좌표에서 추출한 컷만 분리 노드로 다시 사용한다. 여러 컷을 행 우선 순서로 하나의 영상 노드에 연결하고 새로고침 뒤 시트, 컷과 입력선을 확인할 수 있다.
- C2·C3·C4·C9. 빈 캔버스, 노드, 연결선을 가리킨 작업 메뉴에서 해당 대상에 적용되는 동작을 연다. 노드 메뉴의 검색, 업로드와 붙여넣기는 캔버스 좌표에서 동작한다. 작업 메뉴와 선택 노드 버튼은 터치로 열 수 있다. 저장한 자산은 프로젝트 전환과 새로고침 뒤에도 보관함에서 사용한다.
