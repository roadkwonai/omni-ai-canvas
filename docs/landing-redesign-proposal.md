# 랜딩 개편 제안

2026-11-24. 1~2단계는 구현했고 3~4단계는 제안으로 남아 있다. 아래 "지금"은 개편 전 화면이다. 시안은 [HTML](mockups/landing-redesign.html), [1440px 캡처](mockups/landing-redesign-1440.png), [390px 캡처](mockups/landing-redesign-390.png)이고, 로고·부제·마스코트·공유 이미지는 현재 랜딩에 이미 적용했다.

## 결론

1. **첫 화면에서 무엇인지 말한다.** 제목 "한 줄을, 한 편으로."는 남기고 바로 아래에 부제를 둔다.
2. **결과 영상을 먼저 보여 준다.** 겹친 그림 두 장 대신 완성 영상과 그 재료 네 칸을 한 틀에 놓는다.
3. **새 기능을 넣는다.** 여러 화자 대사, AI 연기 지시, 로컬 목소리가 현재 랜딩에 없다.
4. **비용과 보관을 본문으로 올린다.** 지금은 FAQ를 눌러야 보인다.
5. **도구 11개의 글 목록을 5개로 줄인다.** 나머지는 가이드에서 찾는다.

## 지금 화면에서 확인한 것

Ego Browser로 1440·390·320px을 재고 전체 화면을 캡처했다.

| 확인한 것 | 근거 | 문제 |
| --- | --- | --- |
| 첫 화면에 제품의 정의가 없다 | 제목과 설명에 "AI 모델", "영상 제작실"이 없다 | 이름만 보고는 이미지 도구인지 보드 도구인지 알기 어렵다 |
| 보드 그림을 읽을 수 없다 | 히어로 보드 폭이 1440px에서 약 440px, 390px에서 약 300px | 노드 이름이 점처럼 보여 증거가 되지 않는다 |
| 390px에서 키프레임 설명이 보드 그림에 닿는다 | 보드 그림이 위로 10px 올라간다 | 아래 글자가 틀에 붙어 잘린 듯 보인다 |
| 완성 영상은 네 번째 탭에만 있다 | 제작 과정의 예제 재생 탭 | 결과를 보려면 두 번 움직여야 한다 |
| 도구 구간이 모바일의 30%다 | 390px 전체 6,215px 중 1,868px | 글 11개가 이어지고 그림이 없다 |
| 링크의 절반이 가이드로 나간다 | 링크 30개 중 가이드 15개, 캔버스 열기 3개 | 시작 전에 문서로 빠지기 쉽다 |
| 대사 기능이 "대사를 녹음하거나"로만 적혔다 | 편집·보관의 음악·대사·효과음 항목 | 최근에 만든 차별점이 보이지 않는다 |
| 제작 형식 10개가 같은 크기의 글 칸이다 | 형식 구간 | 고를 기준도, 그 형식으로 시작하는 길도 없다 |
| 비용·보관 답이 접혀 있다 | FAQ 3번과 5번 | 계정과 돈이 드는 도구에서 가장 먼저 묻는 내용이다 |

좋은 점도 있다. 가로 넘침이 없고, 첫 화면 그림 두 장은 합쳐 179KB다. 누르기 어려운 24px 미만 링크가 없고 캔버스 열기의 문구가 세 곳에서 같다. 이 점은 유지한다.

## 화면과 동작

- 결과 영상은 소리 없이 재생하고 일시정지 단추를 둔다. 모션 줄이기를 켠 사람에게는 정지 화면을 보여 준다.
- 재료 네 칸을 누르면 같은 화면의 제작 과정 탭으로 이동한다. 가이드로 보내지 않는다.
- 형식 묶음의 시작 링크는 `/studio?format=…`이 필요하다. 지금은 주소로 형식을 고를 수 없으므로 제작실에 작은 변경이 따른다.
- 대사 구간의 재생 단추는 실제로 만든 짧은 음성 세 개를 쓴다. 배포용이므로 라이선스가 맞는 음성이어야 한다. S2 Pro 결과는 비상업 조건이라 쓰지 않는다.
- 오미는 마지막 안내에만 둔다. 첫 화면은 제작자의 작품이 주인공이다.

| 2 | 문제와 구조, 비용과 보관, 도구 축소, FAQ 정리 | 같은 파일 | 인포그래픽은 이미 있음 |

1단계와 2단계만 해도 결론의 1·2·4·5가 해결된다. 먼저 이 두 단계를 하는 것을 권한다.

## 감수할 점

- 구간이 늘어 페이지가 길어진다. 시안은 1440px에서 6,412px로 지금 4,535px보다 41%, 390px에서 7,408px로 지금 6,215px보다 19% 길다. 짧게 가려면 3번 구간의 불편 세 가지와 6번 핵심 문장을 합친다.
- "여섯 작업 모두 API 키 없이 시작"은 구독 계정 연결이나 로컬 설치가 필요하다는 뜻이다. 본문에서 조건을 함께 적는다.
- 제작자 후기와 완성작 수 같은 증거는 없다. 만들지 않고, 실제 작품이 생기면 2번 구간에 넣는다.
- 이 제안에는 방문자 행동 자료가 없다. 로컬 전용이라 분석 도구도 없다. 판단 근거는 화면 점검과 기존 설계 문서다.

## 1~2단계 구현 결과

| 항목 | 개편 전 | 개편 후 |
| --- | --- | --- |
| 가이드로 나가는 링크 | 30개 중 15개 | 34개 중 11개 (모바일 메뉴의 중복 5개 포함) |
| 모바일 머리글 높이 | 115px 두 줄 | 62px 한 줄과 메뉴 |
| 페이지 길이 1440px / 390px | 4,535px / 6,215px | 6,097px / 7,457px |

결과 영상과 부제가 1440×900, 390×844, 320×700 첫 화면에 들어온다. 길이는 1440px에서 34%, 390px에서 20% 늘었다. 320px 머리글은 이름을 온전히 보이려고 캔버스 열기를 뺐다. 바로 아래 첫 화면의 단추로 연다.

1440·768·390·320px에서 가로 넘침이 없고, 메뉴 열기·Esc·포커스 복귀·구간 이동, 자료에서 탭 열기와 다시 누르기, 영상 멈추기, 모션 줄이기의 정지 상태를 Ego Browser에서 확인했다. 실제 스마트폰과 VoiceOver에서는 확인하지 않았다.

## 문구 보정

2026-11-24에 랜딩, 부제, 인포그래픽과 도표의 문구를 다시 다듬었다. 위 문구 표의 제목과 부제는 보정 전 제안이다. 지금 제목은 "대본 한 줄이 영상 한 편이 돼요", 부제는 "대본부터 완성 영상까지 여러 AI 모델을 한 보드에서 쓰는 제작실"이다. 제목에는 마침표를 쓰지 않고, 조사나 "~에서"로 끝나는 문장 대신 서술어가 있는 문장을 쓴다.
