# Newtake 캔버스 실측

## 프롬프트와 디렉터 스튜디오 · 2026-11-23

Aside Browser에서 [검증 캔버스](https://www.newtake.ai/ko/canvas?spaceId=282902&projectId=a28f7a816c4043e38a4190e352e23d79)의 캐릭터 설정도와 비디오 노드를 선택했다. 프롬프트 위에 업로드·캔버스 참조와 번호가 붙은 미리보기가 있었다. GPT Image 2의 출력 메뉴에서 표준·고화질, 1K·2K·4K, 16:9, 1·2·4장 선택을 확인했다. Kling 4.0 Flash에서 모델·입력 방식·출력 메뉴를 각각 열었다. 선택된 입력 방식은 올인원 참조, 출력 요약은 스마트 모드·720P·5초·1개였다. 모델과 입력 방식에 따라 사용할 수 없는 항목은 비활성으로 표시됐다.

연결된 디렉터 노드에서는 색감 18개, 조명 14개, 자동을 포함한 미술 스타일 11개와 촬영 설정의 카메라·렌즈·초점 거리·조리개를 확인했다. 내러티브는 이 캔버스에서 비활성으로 표시됐다. 공개 페이지에서도 프롬프트, 스타일, 촬영, 모델 선택을 한곳에 두는 흐름을 확인할 수 있다. [Newtake Director Studio](https://www.newtake.ai/director-studio) · [World Camera](https://www.newtake.ai/worldcamera)

Omni AI Canvas에서는 아래 작업을 연결한다.

- 프롬프트 위에서 로컬 파일과 캔버스 참조를 확인한다. 이미지·영상 파일의 종류와 입력 위치는 공급사 모델 사양으로 검증한다. 프롬프트 옆에서 모델, 입력 방식과 출력 규격을 고른다.
- 씬 전체에 클립 하나를 만들거나 연결된 샷마다 영상을 요청한다. 작업 기록에서 영상이나 이미지를 미리보고 노드에 적용한다. 한 번의 요청은 결과 하나를 대상으로 한다.
- 디렉터 스튜디오에서 촬영·색감·조명·미술·장면 전개를 시각 카드로 선택한다. 장비 이미지와 장면 비교 시트는 내장 이미지 생성 도구로 제작했다. 프레이밍 미리보기는 연결 이미지 또는 예제 프레임을 사용한다. 저장한 연출은 실제 생성 요청에 텍스트 지시로 포함되며 결과는 선택 모델에서 확인한다.

### 내러티브 메뉴 재확인

공개 Director Studio의 내러티브 메뉴에서 장르 10개와 리듬 5개를 각각 조작해 확인했다. 검증 캔버스에 있던 비활성 상태와 별도로, 공개 화면에서는 장르와 리듬을 독립적으로 고를 수 있었다. 캔버스는 두 분류를 모두 제공하며 기존 자체 장면 전개를 6개에서 12개로 늘렸다. 장르는 이야기의 성격, 리듬은 컷의 길이와 전환, 전개는 사건과 정보의 순서에 적용한다. [Newtake 공식 Director Studio](https://www.newtake.ai/director-studio)

초점 거리 미리보기에서는 같은 승강장 장면을 고정 위치에서 18~135mm로 비교한다. 풀프레임 36mm 가로폭과 초점 거리로 가로 화각을 계산한다. 이 미리보기는 인물과 배경이 프레임에 들어오는 범위를 보여준다. [Nikon의 초점 거리 안내](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)

### 비교 이미지 제작 지시

- 조명 비교는 같은 역 실내 인물을 창가 자연광, 렘브란트, 스플릿, 실루엣, 역광, 버터플라이, 직사광, 교차광, 실내조명, 톱 라이트, 아래쪽 조명, 반사광 순으로 촬영한 4×3 시트다.
- 색감 비교는 안개 낀 승강장의 같은 인물과 구도를 자연색, 냉색, 황금색, 느와르, 파스텔, 흑백, 청록과 주황, 빈티지, 흙빛, 원색, 보라색, 녹색으로 비교한다. 열두 칸의 원본은 `style-contact.webp`에 보관한다. 화면은 열여덟 칸인 `palette-contact.webp`를 쓴다. 흙빛·회녹색·분홍·복숭아·남색·석양·자홍 일곱 칸은 자연색 칸을 암부·중간·명부 색으로 보정해 만들었고, `tests/node-director-palette.test.ts`가 카드 이름과 예제 색을 대조한다.
- 연출 시트는 의상과 공간, 단서나 감정 변화 등 이야기 전개를 보여 주는 열두 장면이다. 장비 시트에는 시네마 카메라와 렌즈 유형, 네 가지 추가 미술 스타일을 담았다. 파일은 `public/director/*-contact.webp`에 있다.
- 추가 예제는 중앙에 인물이 선 승강장, 대치·시간 생략·교차·반전·여운 장면, 장르와 리듬을 보여 주는 5×3 카드 시트다. 도입 카드는 넘어지는 유리컵과 물방울을 별도로 생성해 교체했다. 새 예제는 `public/director/`의 `focal-platform.webp`, `narrative-contact.webp`, `genre-rhythm-contact.webp`, `hook-spill.webp`에 있다.

2026-11-22에 로그인된 Newtake의 기존 빈 캔버스에서 화면과 메뉴를 확인했다. 노드 생성이나 메시지 전송, 생성 실행은 하지 않았다. 확인 당시 캔버스에는 노드가 0개였다. 아래 내용은 관찰한 화면과 그로부터 도출한 설계 제안이다.

## 캔버스와 노드

- 왼쪽 도구 모음은 노드 추가, 이동, 손 도구, 생성 기록, 모든 기능, 단축키와 사용 가이드를 제공한다. 빈 캔버스에서 더블클릭해 노드를 만들 수 있다고 표시한다.
- 노드 추가 메뉴에는 텍스트, 스크립트, 이미지, 비디오, 오디오, 스마트 편집, 비디오 스위치, 디렉터 스튜디오, 디렉터 콘솔이 있다. 업로드 및 생성 기록에서 리소스를 선택하는 항목도 있다.
- 캔버스 하단에는 캔버스 정리, 미니맵 전환, 노드 연결선 숨기기, 그리드 스냅, 확대·축소 옵션이 있다.
- 단축키 안내에는 그룹화·그룹 해제, 스토리보드 그룹 병합, 연결, 노드와 연결선 복사, 생성, 새 노드 만들기, 사본 만들기, 화면 맞춤, 이동, 실행 취소·다시 실행, 노드 검색과 삭제가 표시된다.
- 워크스페이스 패널은 캔버스, 자산, 크리에이션 키트를 구분한다. 크리에이션 키트에는 캐스팅 스튜디오, 스타일, 특수 효과, 프리셋 영역이 있다.

## Agent와 모델

- 상단 Agent를 열면 별도 채팅 패널이 나타난다. 대화 기록, 패널 너비 조정, 첨부, 모델 선택, Skill, 수동 생성, 음성 입력이 보인다.
- 입력란은 `@`로 워크플로, 노드, 리소스를 참조할 수 있다고 안내한다. 스킬 추천 카드가 채팅 시작 화면에 보인다.
- 모델 선택창은 이미지와 비디오를 구분한다. 관찰 당시 GPT Image 계열, Seedream, Nano Banana, Midjourney와 Seedance, Wan, MiniMax, Kling 계열 등 여러 선택지가 표시됐다. 모델 가용성과 이름은 변경될 수 있다.
- 노드가 비어 있어 실제 노드의 포트, 세부 입력 설정, 생성 결과와 예상 비용은 이번 실측에서 확인하지 못했다.

## MCP 연결

상단 MCP 안내창은 Newtake Remote MCP 주소 `https://mcp.newtake.ai/mcp`를 제공하고 Newtake 계정 인증을 안내한다. 연결 대상 선택지에는 ChatGPT, Codex, Claude, Claude Code, Hermes가 표시됐다. 실제 연결 및 제공 도구, 과금, 권한은 이번 실측에서 확인하지 않았다.

## 제품 설계에 적용할 사항

1. 채팅과 캔버스를 함께 보여주고 선택 노드와 연결된 참조를 작업 맥락으로 전달한다.
2. 캐릭터, 문서, 이미지, 영상 자산을 다시 활용할 수 있도록 자산 목록과 생성 기록을 제공한다.
3. 노드 생성뿐 아니라 연결, 복사, 그룹, 검색, 화면 맞춤과 실행 취소를 점진적으로 제공한다.
4. 제공자별 연결 상태와 지원되는 모델·작업을 표시하고, 각 연동의 인증과 크레딧 조건을 확인한 뒤 실행한다.
5. 제작 전 모델 설정과 참조 입력을 검토하고, 결과물과 실행 상태를 노드에 연결한다.

## 후속 메뉴 확인 · 2026-11-22

기존 빈 캔버스를 다시 열어 메뉴만 확인했다. **모든 기능**에는 동영상의 업스케일·프레임 캡처·구간 잘라내기·리메이크·스마트 이어쓰기·피사체/자막 제거·음성 분리, 이미지의 다각도·인물 질감·720도 파노라마·9분할·조명·요소/레이어 편집, 오디오의 자르기·분할·속도 조절 항목이 보였다. 유틸리티에는 Casting Studio, Director Studio, Newtake Switch, 영상 편집기, 3D Director가 있었다. 각 항목을 실행하지 않아 결과와 이용 조건은 확인하지 못했다.

생성 기록 창은 생성 기록·저장 에셋·내 업로드를 구분하고, 현재/모든 프로젝트와 이미지·비디오·오디오 필터를 제공했다. 창을 닫아 원래 화면으로 복원했다. Switch의 참조 영상 동작 전이와 요소 교체는 [Newtake 공식 안내](https://www.newtake.ai/landing/switch)에서 설명한다.
