인물마다 목소리를 정하고 연기시켜요

목소리를 찾고, 캐릭터에 저장하고, 대본을 한 번에 음성으로 만들어요.

  • 1. 목소리 찾기

    공개 목소리를 한국어로 검색

    Fish Audio의 공개 목소리를 성별, 나이대, 태그로 좁히고 들어 봐요. 캐릭터에 어울리는 목소리를 추천받을 수도 있어요.

  • 2. 캐릭터에 저장

    TTS 등록 샘플

    마음에 드는 음성을 캐릭터 시트에 저장해 두고 다음 대사의 기준으로 써요. Higgsfield 개인 목소리로 등록할 수도 있어요.

  • 3. 내 컴퓨터에서

    API 키 없이 만들기

    Apple Silicon Mac에서는 로컬 모델로 음성을 만들어요. 녹음한 내 목소리를 참조로 쓸 수 있어요.
