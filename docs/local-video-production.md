# 컷 분석에서 로컬 영상 제작까지

## 제작 흐름

레퍼런스에서 반복할 연출을 먼저 고르고, 새 작품의 소재·대사·인물은 별도로 설계한다. 화면 변화와 자막은 원본 시각에 기록하고, 프리셋에는 새 길이에 맞게 늘리거나 줄일 수 있는 구간 비율을 저장한다. 모션그래픽은 검토가 끝난 장면 명세를 로컬 렌더러로 보낸다. [제작 흐름 도식](diagrams/reference-motion.html)

| 제작자가 할 일 | Omni AI Canvas에서 사용하는 자료 | 결과물 |
| --- | --- | --- |
| 빠른 쇼츠의 훅과 전환 확인 | 컷 후보와 번호가 붙은 화면 시트, 원본 플레이어, 화면 문자 위치, 제공 자막 | 컷별 구도·자막·변화 해석. 놓친 경계는 원본 시각으로 보정하고 원하는 구간을 다시 분석 |
| 같은 리듬으로 새 주제 기획 | 내 콘셉트, 검토한 프리셋, 감독 에이전트 | Neon 개인 프리셋과 연결된 씬·대본·샷·키프레임 제작 보드 |
| 숏폼 또는 긴 설명 영상 제작 | 목표 화면비·길이, 레시피, 직접 편집한 장면 문구, 내 프로젝트 이미지 | 로컬 MP4와 재편집 가능한 영상 노드. 타임라인에서 음악·효과음을 조합 |
| 배우 상태와 시점 통일 | 얼굴·포즈·의상 참조, 조명·표정·질감 지시 | 캐릭터 연출 키트. 선택한 3면도·25컷을 제작 지시와 참조 연결로 배치 |

## 실증 작품

Smithsonian 쇼츠의 컷 후보 32개에서 얻은 연출을 작은 책방의 복원 이야기로 바꿨다. 감독 제작 보드를 저장한 다음 같은 프리셋으로 18초짜리 세로 모션 테이크를 추가했다. 다른 콘텐츠에 적용할 때에는 원본 관찰, 에이전트 해석, 사용자 수정본을 차례로 확인할 수 있다. [실계정 검증과 작품](shorts-live-verification.md)

## 제작 기술별 적용

- **모션그래픽과 숏폼·롱폼.** 기획은 텍스트 구독 에이전트가 맡을 수 있다. 시간, 레이어, 등장 순서, 텍스트 계층과 카메라·배경의 독립 움직임은 로컬 명세에 담는다. 갤러리에서 찾은 작품은 허용된 원본 파일이나 공개 쇼츠를 분석하거나 구도·타이밍을 직접 기록해 프리셋으로 사용한다. 갤러리를 선택하면 해당 자료를 열고 연구할 연출 방향을 모션 기획에 전달한다. [8가지 스킬·cokacmotion·갤러리와 튜토리얼 검토](motion-skills-research.md) · [레시피와 렌더 예제](local-motion-recipes.md)
- **가상 인물 제작.** 얼굴 정체성, 포즈, 의상, 광원과 표정이 서로 다른 노드에서 관리되면 한 요소만 교체하고 이전 상태와 비교할 수 있다. Newtake 영상의 피부 질감·카메라 시점·그리드·조명·표정·턴어라운드를 Omni AI Canvas의 연출 작업에 대응시켰다. 이번 구현에서는 키트를 배치한 뒤 생성 여부와 모델을 노드별로 결정한다. [인물 연출 자료와 기능 대응](portrait-production-design.md)
- **Blender·Tripo 3D 제작.** Omni AI Canvas에서 기존 GLB 캐릭터·배경을 가져와 본 포즈와 내장 액션, 카메라·조명을 지정하고 로컬 Blender로 프리비즈·최종 테이크를 렌더할 수 있다. 프레임 단위 재시작과 외부 리타기팅 연동은 후속 범위다. 유료 3D 제작은 기존 모델로 부족할 때 선택하는 별도 경로다. 이 설계의 인수 기준은 한 캐릭터의 동작·카메라·조명을 수정해 해당 샷만 재렌더하고 같은 편집 시간축에서 교체하는 것이다. [Blender·Tripo 영상 분석, 인터페이스와 단계별 인수 기준](blender-tripo-production.md)

## 선택 기준

빠른 자막이나 컷을 자세히 보고 싶을 때에는 2~4컷의 원본 시각부터 검토한다. 같은 인물이 등장하는 연작은 얼굴·의상·조명을 고정한 키트를 먼저 만든다. 설명 영상은 카드·텍스트·도형과 컷아웃으로 짧은 시안을 렌더해 읽는 시간을 확인하고, 같은 명세로 장면을 늘린다. 카메라가 피사체 뒤로 돌아가는 샷이나 실제 관절 동작이 필요한 경우에는 3D 파이프라인이 적합하다. 로컬 모션과 Blender 렌더 결과의 음향은 타임라인에서 추가한다. [실제 Blender 샷과 MP4](blender-scene-verification.md)
